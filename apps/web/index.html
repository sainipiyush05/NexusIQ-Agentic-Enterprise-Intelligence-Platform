📚 Deep-Dive: Platform Modules & How to Use Them
Everything you need to know about each feature and what to expect when using it:
⚡

Agentic Copilot

POST /v1/query

The centerpiece of NexusIQ. Orchestrates multiple subsystems autonomously to answer composite business questions that require both unstructured policies and structured database records.

  • How to use: Select a question pill or type your own composite query in the textarea and click Execute Workflow.
  • What it does: The LLM planner decomposes the question into tool calls (retrieval, SQL, churn, FX), bounded by a strict 3-tool budget to eliminate infinite execution loops.
  • What to inspect: Look at the Execution Spans showing each tool step, latency, and source citations with clickable document links.
🔍

Search & Grounded RAG

POST /v1/search & /v1/answer

High-precision enterprise policy discovery across refund policies, SLAs, support tiers, and compliance guidelines.

  • Hybrid Engine: Fuses BM25 keyword matching with dense MiniLM vector similarity using Reciprocal Rank Fusion (RRF), followed by Cross-Encoder reranking.
  • Grounded Citations: In Cited Extracts mode, answers include exact quoted excerpts. If information is not in the corpus, the engine strictly abstains rather than hallucinating.
  • What to try: Test "Enterprise refund window in APAC" for verified answers, or "corporate cryptocurrency trading" to observe safe abstention.
📊

Read-Only SQL Analytics

POST /v1/sql

Execute analytical queries directly against PostgreSQL/SQLite tables: customers, subscriptions, orders, and tickets.

  • AST Safety Guardrail: Before execution, the SQL Abstract Syntax Tree is inspected. Any write/mutation (DROP, DELETE, UPDATE, INSERT, ALTER) is blocked instantly with HTTP 400.
  • How to use: Pick any pre-built prompt pill or write any valid SELECT query with GROUP BY, JOIN, or aggregations.
  • Try a write test: Click the "Forbidden Write Query" pill to verify that destructive SQL is rejected safely.
🔮

ML Churn Prediction

POST /v1/predict/churn

Scores the probability of a customer cancelling their SaaS subscription within the next 90 days.

  • How it works: Evaluates temporal features including monthly recurring revenue (MRR), subscription tier, seat count, and support ticket velocity.
  • Calibration: Outputs probabilities calibrated for business decision-making with MLflow experiment tracking and SHAP feature importance.
  • How to use: Enter any customer ID between C0001 and C0200 and click Score Churn. Risk is color-coded: Green (<15%), Amber (15-30%), Red (>30%).
💱

FX Reference Rates

GET /v1/fx

Standardized foreign exchange rate lookup used for multi-currency contracts, pricing conversions, and financial analytics.

  • Data Source: Verified financial API (Frankfurter / ECB) with automatic in-memory caching and resilient offline fallbacks.
  • How to use: Choose Base currency (USD, EUR, GBP), Quote currency (EUR, USD, GBP, INR), and date, then click Fetch Rate.
  • Integration: Also directly callable as a tool by the Agentic Copilot for currency-dependent calculations.
📁

Ingestion Pipeline

POST /v1/documents

Asynchronous document upload and indexing pipeline for enterprise knowledge policies.

  • Background Worker: Ingestion jobs execute asynchronously without blocking API request latency. The frontend polls job status until completion.
  • Processing Steps: Header-aware markdown chunking, SHA-256 deduplication, vector embedding generation, and live index update.
  • Permissions: Requires Admin role (switch role in top right header to test permission checks).
📈

Observability & Traces

GET /v1/observability/summary & /v1/traces

Comprehensive observability dashboard providing real-time system metrics, operational SLO alerts, and distributed request traces.

  • Golden Signals: Live metrics for total request count, error rates, P95 latency (ms), and Redis/memory cache hit rate.
  • SLO Alerts: Real-time rule evaluation (e.g. LatencySLOViolated > 500ms, ErrorRateElevated > 5%).
  • Distributed Traces: Inspect per-request spans, method, user role, HTTP status code, duration, and individual tool execution timings.
🛒

Olist Marketplace

POST /v1/olist/search & GET /v1/olist/status

Enterprise-scale e-commerce dataset loaded into isolated PostgreSQL olist schema for scale validation (550,688 business rows, 1.55M total rows).

  • Scale Validation: 99,441 customers, 99,441 orders, 112,650 items, 32,951 products, 3,095 sellers.
  • Full-Text Review Search: Search 42,697 Portuguese customer reviews with source attribution, star rating, and full-text relevance ranking.
  • Schema Isolation: Maintained in separate PostgreSQL tables to prevent pollution of SaaS policy RAG benchmarks or tenant-scoped ACLs.
